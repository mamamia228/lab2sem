## Ход выполнения работы

### 1. Подготовка данных

В рамках лабораторной работы был использован набор данных, содержащий информацию о клиентах кредитной организации и наличии либо отсутствии кредитного дефолта.

На этапе подготовки данных были выполнены следующие действия:

* произведена загрузка обучающего и тестового наборов данных;
* изучена структура данных с помощью метода `info()`;
* выполнен анализ пропущенных значений;
* вычислены средние значения признаков;
* пропущенные значения были заменены средними значениями;
* выделены признаки и целевая переменная.

После подготовки были сформированы:

* матрица признаков для обучения моделей;
* вектор целевых значений.

---

### 2. Построение моделей

Для решения задачи бинарной классификации были использованы следующие алгоритмы.

#### Logistic Regression

Логистическая регрессия является базовым алгоритмом классификации и позволяет оценивать вероятность принадлежности объекта к определённому классу.

Модель была обучена на подготовленном наборе данных и использована для прогнозирования вероятности кредитного дефолта.

#### Random Forest

Random Forest представляет собой ансамбль решающих деревьев.

Каждое дерево обучается независимо, а итоговое решение формируется на основе коллективного голосования всех деревьев. Такой подход позволяет повысить устойчивость модели и уменьшить вероятность переобучения.

После обучения обеих моделей были получены прогнозы для тестового набора данных.

---

### 3. Оценка качества моделей

Для оценки эффективности алгоритмов использовались следующие показатели:

* Accuracy;
* Precision;
* Recall;
* F1-score;
* ROC-AUC.

Также были построены ROC-кривые для визуального сравнения моделей.

Результаты показали, что модель Random Forest обеспечивает более высокое качество классификации по сравнению с Logistic Regression.

---

### 4. Самостоятельное исследование

В рамках самостоятельной части работы были дополнительно исследованы следующие алгоритмы:

#### k-Nearest Neighbors (kNN)

Алгоритм классифицирует объекты на основе ближайших соседей в пространстве признаков. Несмотря на простоту реализации, качество классификации оказалось ниже по сравнению с ансамблевыми методами.

#### Support Vector Machine (SVM)

Метод опорных векторов строит оптимальную разделяющую гиперплоскость между классами. Модель продемонстрировала удовлетворительные результаты, однако уступила ансамблевым алгоритмам по качеству классификации.

#### Gradient Boosting

Алгоритм градиентного бустинга формирует последовательность моделей, каждая из которых исправляет ошибки предыдущей. Данный подход позволил получить высокие значения метрики ROC-AUC.

#### HistGradientBoosting

HistGradientBoosting является усовершенствованной реализацией градиентного бустинга, оптимизированной для работы с большими наборами данных. По результатам экспериментов модель показала одно из лучших качеств классификации.

---

### 5. Сравнение результатов

В результате исследования были получены следующие выводы:

* ансамблевые методы показали наилучшие результаты;
* модели Gradient Boosting и HistGradientBoosting продемонстрировали наиболее высокие значения ROC-AUC;
* Random Forest также показал высокое качество прогнозирования;
* Logistic Regression обеспечила стабильные результаты и хорошую интерпретируемость;
* модели kNN и SVM уступили ансамблевым алгоритмам по качеству классификации.
