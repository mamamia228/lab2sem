# Лабораторная работа №4

## Тема

Исследование методов машинного обучения для прогнозирования кредитного дефолта заемщиков.

## Цель работы

Изучить применение алгоритмов классификации для решения задачи прогнозирования кредитного дефолта, освоить методы подготовки данных, обучения моделей и оценки качества классификации с использованием различных метрик.

## Задачи работы

1. Изучить структуру и особенности набора данных о кредитных клиентах.
2. Выполнить предварительную обработку данных.
3. Обучить модели Logistic Regression и Random Forest.
4. Оценить качество моделей с использованием метрик классификации.
5. Построить ROC-кривые и вычислить значение ROC-AUC.
6. Провести самостоятельное исследование дополнительных алгоритмов машинного обучения.
7. Сравнить полученные результаты и определить наиболее эффективную модель.

## Ход выполнения работы

### 1. Подготовка данных

Для выполнения работы был использован набор данных, содержащий информацию о клиентах кредитной организации и факте наличия или отсутствия кредитного дефолта.

На этапе предварительной обработки были выполнены следующие действия:

* загружен обучающий набор данных;
* исследована структура данных с помощью метода `info()`;
* обнаружены и обработаны пропущенные значения;
* вычислены средние значения признаков;
* выполнено заполнение пропусков;
* выделены признаки и целевая переменная.

После подготовки данных были сформированы:

* матрица признаков (`training_points`);
* вектор целевых значений (`training_values`).

### 2. Построение моделей

Для решения задачи классификации были использованы следующие модели:

#### Logistic Regression

Логистическая регрессия является одним из наиболее распространённых методов бинарной классификации. Данная модель была обучена на подготовленном наборе данных и использована для прогнозирования вероятности дефолта клиента.

#### Random Forest

Random Forest представляет собой ансамблевый алгоритм, основанный на построении множества решающих деревьев. Итоговое решение принимается на основе голосования отдельных деревьев, что позволяет повысить устойчивость модели и качество прогнозирования.

После обучения моделей были получены прогнозы для тестового набора данных.

### 3. Оценка качества моделей

Для оценки качества классификации использовались следующие метрики:

* Accuracy;
* Precision;
* Recall;
* F1-score;
* ROC-AUC.

Также были построены ROC-кривые для визуального сравнения качества моделей.

По результатам экспериментов было установлено, что Random Forest обеспечивает более высокое качество классификации по сравнению с Logistic Regression.

### 4. Самостоятельное исследование

Дополнительно были рассмотрены следующие алгоритмы машинного обучения:

#### k-Nearest Neighbors (kNN)

Алгоритм классифицирует объект на основе ближайших соседей в пространстве признаков. Несмотря на простоту реализации, качество модели оказалось ниже по сравнению с ансамблевыми методами.

#### Support Vector Machine (SVM)

Метод опорных векторов позволяет строить разделяющую гиперплоскость между классами. Модель показала удовлетворительные результаты, однако уступила ансамблевым алгоритмам по значению ROC-AUC.

#### Gradient Boosting

Алгоритм бустинга последовательно обучает набор слабых моделей, исправляя ошибки предыдущих этапов. Данный метод продемонстрировал высокое качество классификации.

#### HistGradientBoosting

Усовершенствованный вариант градиентного бустинга, оптимизированный для работы с большими объёмами данных. По результатам экспериментов модель показала одно из лучших значений ROC-AUC.

### 5. Сравнение результатов

В результате проведённого исследования было выполнено сравнение нескольких алгоритмов классификации.

Наиболее высокое качество продемонстрировали методы:

* Gradient Boosting;
* HistGradientBoosting;
* Random Forest.

Логистическая регрессия показала более низкие результаты, однако сохранила хорошую интерпретируемость и простоту использования.

Алгоритмы kNN и SVM уступили ансамблевым методам по качеству классификации на рассматриваемом наборе данных.

## Вывод

В ходе выполнения лабораторной работы были изучены методы машинного обучения для прогнозирования кредитного дефолта клиентов. Были выполнены этапы подготовки данных, обучения моделей и оценки качества классификации.

Дополнительно были исследованы алгоритмы kNN, SVM, Gradient Boosting и HistGradientBoosting. Сравнение результатов показало, что наилучшее качество по метрике ROC-AUC обеспечивают ансамблевые методы бустинга, которые наиболее эффективно выявляют сложные зависимости в данных кредитного скоринга.

Полученные результаты подтверждают эффективность современных ансамблевых алгоритмов при решении задач кредитного риска и прогнозирования дефолта заемщиков.
