## 6. Создание новых признаков

Для дальнейшего анализа был создан новый столбец `average_score`.

В нём рассчитывался средний балл студента по математике, чтению и письму:

```python
df["average_score"] = df[
    ["math_score", "reading_score", "writing_score"]
].mean(axis=1)
```

Также был создан категориальный признак `score_level`, характеризующий общий уровень успеваемости студента:

```python
df["score_level"] = pd.cut(
    df["average_score"],
    bins=[0, 60, 75, 90, 100],
    labels=["low", "medium", "high", "excellent"],
    include_lowest=True
)
```

Для признака `score_level` были определены следующие категории:

| Категория   | Диапазон среднего балла |
| ----------- | ----------------------: |
| `low`       |              от 0 до 60 |
| `medium`    |             от 60 до 75 |
| `high`      |             от 75 до 90 |
| `excellent` |            от 90 до 100 |

Таким образом, каждый студент был отнесён к определённой категории успеваемости.

## 16. Настройка SourceCraft CI/CD

Для автоматического выполнения ноутбука был настроен файл:

```text
.sourcecraft/ci.yaml
```

В конфигурации были предусмотрены следующие этапы:

1. Создание контейнера с Python.
2. Обновление пакетного менеджера `pip`.
3. Установка зависимостей из `requirements.txt`.
4. Открытие файла `lab_template.ipynb`.
5. Добавление в ноутбук markdown-ячейки с информацией о выполнении в SourceCraft CI.
6. Автоматическое выполнение всех ячеек ноутбука.
7. Создание выполненного файла `executed_lab.ipynb`.
8. Преобразование выполненного ноутбука в HTML-отчёт.
9. Сохранение полученных файлов в качестве артефактов.

Для выполнения ноутбука использовалась команда:

```text
jupyter nbconvert --to notebook --execute lab_template.ipynb --output executed_lab.ipynb
```

Для создания HTML-отчёта использовалась команда:

```text
jupyter nbconvert --to html executed_lab.ipynb --output report.html
```

После успешного выполнения CI должны быть сформированы следующие артефакты:

| Артефакт             | Назначение                                           |
| -------------------- | ---------------------------------------------------- |
| `executed_lab.ipynb` | выполненный ноутбук с результатами работы всех ячеек |
| `report.html`        | HTML-версия выполненного ноутбука                    |

В конец ноутбука также добавляется текстовая ячейка, подтверждающая, что выполнение происходило на раннере SourceCraft, а не на локальном компьютере или в Google Colaboratory.

**Место для рисунка:** успешный запуск SourceCraft CI/CD.
