## Обработка пропущенных значений

Для повышения качества данных были применены различные методы заполнения пропусков.

### Признак Age

Было вычислено среднее и медианное значение возраста пассажиров. Для заполнения пропусков выбрана медиана, поскольку данный показатель менее чувствителен к выбросам.

```python
df["Age"] = df["Age"].fillna(df["Age"].median())
```

После заполнения был создан дополнительный признак возрастной группы пассажира.

### Признак Embarked

Для заполнения пропущенных значений использовалась мода — наиболее часто встречающееся значение категории.

```python
df["Embarked"] = df["Embarked"].fillna(df["Embarked"].mode()[0])
```

### Признак Cabin

Поскольку доля пропусков была очень высокой, исходный столбец был преобразован. Из значения каюты была выделена первая буква палубы, после чего сформирован новый признак CabinDeck.

## Анализ и обработка выбросов

Для признака Fare был построен boxplot и выполнен поиск выбросов методом межквартильного размаха (IQR).

Была определена верхняя граница допустимых значений:

```python
Upper Bound = Q3 + 1.5 × IQR
```

После выявления экстремальных значений применялась техника winsorization по 95-му процентилю.

Аналогичная процедура была выполнена для признака Age с целью уменьшения влияния редких экстремальных значений.
