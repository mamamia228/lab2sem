# Цель работы

Целью работы являлось освоение методов веб-скрапинга на языке Python, получение практических навыков извлечения данных с веб-сайтов, а также проведение первичного анализа собранной информации.

# Теоретические сведения

Веб-скрапинг представляет собой процесс автоматизированного извлечения информации с веб-страниц. Данный подход широко применяется для сбора данных из открытых источников, мониторинга новостей, анализа публикаций и подготовки наборов данных для последующего исследования.

Для работы использовались следующие библиотеки Python:

* requests — выполнение HTTP-запросов;
* BeautifulSoup — разбор HTML-разметки;
* pandas — хранение и обработка данных;
* matplotlib и seaborn — визуализация результатов анализа.

Основной задачей являлся сбор новостей с сайта ITMO.NEWS с последующим сохранением полученной информации в структурированном виде.

# Ход работы

## Получение списка новостей

На первом этапе был выполнен запрос к сайту ITMO.NEWS и получен перечень опубликованных материалов.

Для каждой новости были извлечены следующие данные:

* идентификатор публикации;
* название новости;
* дата размещения;
* ссылка на страницу новости.

Полученные сведения были сохранены в таблицу для дальнейшей обработки.

## Парсинг страниц отдельных публикаций

После формирования общего списка новостей был выполнен обход каждой страницы отдельно.

Для каждой публикации дополнительно извлекались:

* полный текст новости;
* тематические теги;
* количество просмотров;
* дополнительные метаданные;
* адрес страницы.

Так как структура отдельных страниц может различаться, были реализованы альтернативные способы поиска содержимого, что позволило повысить устойчивость работы парсера.

## Формирование итогового датасета

После завершения сбора данных были сформированы два набора данных:

### news_general.csv

Содержит базовую информацию о публикациях:

* идентификатор;
* заголовок;
* дату публикации;
* ссылку на материал.

### news_content/news_content.csv

Содержит подробную информацию:

* текст публикации;
* теги;
* просмотры;
* URL;
* дополнительные характеристики статьи.

# Первичный анализ данных

После формирования датасета был выполнен базовый анализ полученных материалов.

В ходе анализа были решены следующие задачи:

* подсчитано количество собранных публикаций;
* рассчитана длина каждого текста;
* определены наиболее часто встречающиеся теги;
* исследовано распределение размеров новостей;
* построены графики для визуального анализа данных.

## Анализ длины текстов

Для каждой публикации была вычислена длина текста в символах.

Это позволило оценить:

* средний размер новостей;
* минимальную длину публикации;
* максимальную длину публикации;
* наличие аномально коротких или длинных материалов.

На основе полученных значений была построена гистограмма распределения длин текстов.

## Анализ тегов

Для каждой новости были извлечены тематические теги.

После обработки был сформирован рейтинг наиболее популярных категорий.

Анализ показал, какие направления чаще всего освещаются в новостях университета.

## Визуализация результатов

Для более наглядного представления данных были построены графики:

* распределение длин текстов;
* частота встречаемости тегов;
* основные статистические характеристики датасета.

Использование визуализации позволило быстрее выявить особенности собранного набора данных.
