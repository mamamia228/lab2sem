# Лабораторная работа №5: Регрессия с применением Scikit-Learn

## Цели

1. Изучить применение библиотеки Scikit-Learn для решения задач регрессии.
2. Освоить основные этапы построения регрессионных моделей машинного обучения.
3. Исследовать влияние различных алгоритмов и параметров моделей на точность прогнозирования стоимости недвижимости.

---

## Задачи

В рамках лабораторной работы требовалось:

* загрузить и подготовить данные для обучения моделей;
* построить регрессионные модели с использованием библиотеки Scikit-Learn;
* оценить качество моделей с помощью метрик MAE и RMSE;
* исследовать влияние параметров модели Random Forest;
* протестировать дополнительные алгоритмы регрессии;
* определить наиболее точную модель прогнозирования;
* изучить возможность интеграции обученной модели в веб-приложение.

# Ход работы

## 1. Загрузка и анализ данных

В качестве исходных данных использовался датасет о продаже жилой недвижимости. Целевой переменной являлась стоимость дома.

Для работы с данными использовалась библиотека pandas. После загрузки обучающей и тестовой выборок был проведён анализ структуры набора данных.

На данном этапе были выполнены следующие действия:

* проверка типов данных;
* поиск пропущенных значений;
* анализ статистических характеристик признаков;
* выделение целевой переменной и признаков.

После анализа была сформирована обучающая выборка для последующего построения моделей регрессии.

---

## 2. Предобработка данных

Перед обучением моделей была выполнена подготовка данных.

В ходе обработки:

* удалены признаки, содержащие большое количество пропусков;
* выполнено заполнение отсутствующих значений;
* произведена проверка корректности признаков;
* подготовлены данные для передачи в алгоритмы машинного обучения.

Дополнительно были исследованы признаки с наименьшей значимостью для прогнозирования стоимости недвижимости.

Было установлено, что некоторые характеристики оказывают минимальное влияние на итоговое качество модели и могут быть исключены из набора признаков без существенной потери точности.

---

## 3. Построение базовых моделей регрессии

Для решения задачи прогнозирования стоимости недвижимости были обучены следующие модели:

### Linear Regression

Линейная регрессия использовалась как базовый алгоритм прогнозирования.

Модель строит линейную зависимость между входными признаками и стоимостью недвижимости.

Преимуществами модели являются простота реализации и высокая интерпретируемость результатов.

---

### Random Forest Regressor

Вторая модель была построена на основе алгоритма Random Forest.

Данный алгоритм представляет собой ансамбль решающих деревьев, каждое из которых обучается на случайной части данных.

Итоговый прогноз формируется усреднением результатов всех деревьев.

Модель Random Forest показала более высокую точность по сравнению с линейной регрессией благодаря способности учитывать сложные нелинейные зависимости между признаками.

---

## 4. Оценка качества моделей

Для оценки качества прогнозирования использовались две основные метрики:

### MAE (Mean Absolute Error)

Показывает среднюю абсолютную ошибку прогнозирования.

Метрика позволяет определить, насколько в среднем прогноз модели отличается от фактической стоимости недвижимости.

### RMSE (Root Mean Squared Error)

Показывает среднеквадратичную ошибку прогнозирования.

Поскольку большие ошибки дополнительно штрафуются возведением в квадрат, данная метрика считается одной из наиболее информативных для задач регрессии.

Сравнение моделей показало преимущество Random Forest над линейной регрессией по обеим метрикам качества.

---

## 5. Исследование признаков

В рамках самостоятельной работы был проведён анализ важности признаков.

Из обучающей выборки были исключены пять признаков с минимальным вкладом в итоговый прогноз:

* год реновации;
* количество этажей;
* количество спален;
* состояние объекта;
* площадь подвального помещения.

После удаления данных признаков была повторно выполнена оценка качества моделей.

Результаты показали, что для Random Forest наблюдается небольшое улучшение качества прогнозирования, тогда как для линейной регрессии точность несколько снизилась.

Это подтвердило, что влияние отбора признаков зависит от используемого алгоритма машинного обучения.

---

## 6. Подбор параметров Random Forest

Дополнительно было проведено исследование влияния гиперпараметров модели Random Forest.

Были протестированы различные значения:

* количества деревьев (n_estimators);
* максимальной глубины деревьев (max_depth);
* минимального количества объектов в листе (min_samples_leaf).

Наилучший результат среди исследованных конфигураций показала модель со следующими параметрами:

* n_estimators = 200;
* max_depth = 20;
* min_samples_leaf = 3.

Полученное значение RMSE оказалось ниже, чем у базовой конфигурации Random Forest, что свидетельствует об улучшении качества модели после настройки параметров.

---

## 7. Исследование дополнительных моделей регрессии

Для выполнения самостоятельного задания были протестированы дополнительные алгоритмы машинного обучения:

### Gradient Boosting Regressor

Алгоритм последовательно строит ансамбль моделей, каждая из которых исправляет ошибки предыдущей.

Модель продемонстрировала высокую точность прогнозирования.

### HistGradientBoosting Regressor

Усовершенствованная версия градиентного бустинга, оптимизированная для работы с большими объёмами данных.

По результатам экспериментов данный алгоритм показал наилучшие значения метрик качества среди всех протестированных моделей.

Сравнение результатов показало, что ансамблевые методы бустинга существенно превосходят как линейную регрессию, так и базовый Random Forest.

---

## 8. Интеграция модели в веб-приложение

Для использования обученной модели в веб-сервисе может быть применён следующий алгоритм:

1. Сохранить обученную модель с помощью библиотеки joblib.
2. Создать веб-приложение на Flask, Django или FastAPI.
3. Реализовать API для приёма входных параметров недвижимости.
4. Загружать сохранённую модель при запуске приложения.
5. Передавать пользовательские данные в модель.
6. Выполнять прогноз стоимости недвижимости.
7. Возвращать результат пользователю через веб-интерфейс или API.

Такой подход позволяет использовать модель машинного обучения в реальных информационных системах.
