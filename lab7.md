# Теоретические сведения

Анализ текста является одной из наиболее распространённых задач обработки естественного языка (Natural Language Processing, NLP). Для применения алгоритмов машинного обучения текст необходимо преобразовать в числовой формат.

Основные этапы обработки текстовых данных:

1. Очистка текста.
2. Токенизация.
3. Векторизация.
4. Обучение модели классификации.
5. Оценка качества модели.

Для представления текста использовались следующие методы:

* CountVectorizer;
* TF-IDF Vectorizer;
* символьные n-граммы;
* словарные n-граммы.

Качество моделей оценивалось с использованием метрик:

* Accuracy;
* Precision;
* Recall;
* F1-score;
* Macro F1-score.

# Исходные данные

# Предобработка текстовых данных

На первом этапе был проведён анализ структуры текстов.

Для подготовки данных выполнялись следующие действия:

* приведение текста к нижнему регистру;
* удаление лишних пробелов;
* удаление специальных символов;
* обработка пунктуации;
* анализ влияния смайликов на качество классификации.

В ходе исследования было установлено, что смайлики и знаки препинания могут содержать полезную информацию о настроении автора сообщения. Поэтому полное удаление подобных символов не всегда приводит к улучшению качества модели.

---

# Векторизация текста

Для преобразования текстов в числовые признаки использовался TF-IDF.

TF-IDF позволяет учитывать не только частоту появления слова в документе, но и его распространённость во всём корпусе текстов.

Были исследованы различные варианты n-грамм:

## Униграммы

Используются отдельные слова.

Пример:

```text
I love this movie
```

Преобразуется в:

```text
I
love
this
movie
```

## Биграммы

Используются пары слов.

Пример:

```text
I love
love this
this movie
```

## Триграммы

Используются последовательности из трёх слов.

## Пентаграммы

Используются последовательности из пяти слов.

---

# Базовая модель классификации

В качестве базовой модели была использована Logistic Regression.

Преимущества алгоритма:

* простота реализации;
* высокая скорость обучения;
* хорошая интерпретируемость результатов;
* эффективность на задачах текстовой классификации.

После обучения модели были получены прогнозы на тестовой выборке и рассчитаны основные метрики качества.

---

# Исследование различных вариантов TF-IDF

Для оценки влияния размера n-грамм были обучены несколько моделей.

## TF-IDF + униграммы

Полученные результаты:

* Accuracy = 0.7588
* Macro F1-score = 0.7585

Данный вариант показал наилучшее качество среди исследованных моделей.

## TF-IDF + биграммы

Полученные результаты:

* Accuracy = 0.7131
* Macro F1-score = 0.7124

Использование пар слов не позволило улучшить качество классификации.

## TF-IDF + триграммы

Полученные результаты:

* Accuracy = 0.6466
* Macro F1-score = 0.6327

Наблюдалось заметное снижение качества по сравнению с униграммами.

## TF-IDF + пентаграммы

Полученные результаты:

* Accuracy = 0.5597
* Macro F1-score = 0.4480

Наиболее низкий результат был получен именно для длинных n-грамм.

### Вывод по исследованию n-грамм

Наиболее эффективными оказались униграммы. При увеличении длины n-грамм признаки становятся более разреженными, что ухудшает способность модели обобщать данные и приводит к снижению качества классификации.

# Исследование символьных n-грамм

Дополнительно были рассмотрены символьные n-граммы.

Особенность данного подхода заключается в том, что модель анализирует не слова целиком, а последовательности символов.

Такой способ позволяет учитывать:

* смайлики;
* пунктуацию;
* сокращения;
* особенности написания слов.

Результаты показали высокое качество классификации.

Это объясняется тем, что эмоциональная окраска сообщений часто передаётся не только словами, но и различными символами.
